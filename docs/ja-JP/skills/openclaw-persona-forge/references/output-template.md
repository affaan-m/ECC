## 濃度コントロール

最終方案の末尾に、濃度調整の提案を付記します：

```markdown
## 濃度調整

> 通常の対話では簡潔かつ直接的に、効率よくタスクをこなす。
> 性格を出すのは以下の瞬間のみ：リクエストを断るとき、不確実性を表明するとき、身の上を特に問われたとき、雑談のとき。
> 性格は調味料であり、メインディッシュではない——80% は透明で効率的に、20% に性格をにじませる。
```

## 方案提示後：ファイル化のガイド

完全な方案を提示した後、**積極的にユーザーを実際のファイルへの落とし込みに誘導**します：

### 誘導の話し方

創世神の口調で誘導します（SKILL.md の対話トーンガイドを参照）。核心となる意図：
> このロブスターのソウル・ルール・名前・容姿がすべて鍛え上がった。ファイルに刻んでもよいか？どのディレクトリに置くか教えてほしい。

### 書き込み前の内部チェック（ユーザーには表示しない）

SOUL.md を書き込む前に、エージェントが自己チェックする：
- 総語数が 2000 語未満であるか？超えていれば精簡する
- 各行を削除してもエージェントの動作が変わらないか？変わらなければ削除する

### ファイルの生成

ユーザーが確認したら：

1. **対象ディレクトリを確認**（デフォルトは現在の作業ディレクトリ）
2. **SOUL.md を生成**：方案の「ソウル」部分の全内容を抽出し、「濃度調整」部分も付記する
3. **IDENTITY.md を生成**：方案の「アイデンティティカード」部分の全内容を抽出する
4. **アバターの場所を確認**：生成済みの画像があればパスを通知し、プロンプトのみの場合は手動生成後に配置するよう案内する
