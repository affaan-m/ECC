## Dropped agent tool grants

- WebSearch and WebFetch grants are dropped: Vibe reaches the web through connectors, not agent tool grants
- mcp__* grants are dropped: MCP tool names are server-specific and do not resolve inside a Vibe plugin

## Excluded hook surfaces

| Surface | Reason |
| --- | --- |
| PostToolUse observers (observe-runner, ecc-context-monitor, posttooluse-dispatcher) | Claude Code async hook execution (async: true) has no Vibe equivalent; every Vibe hook runs synchronously in the tool-call chain |
| Stop hooks (7 entries in hooks/hooks.json) | They read Claude Code session transcript state; Vibe post_agent payloads do not carry the same transcript schema (follow-up work) |
| UserPromptSubmit / SessionStart / SessionEnd / PreCompact hooks | Vibe exposes only pre_tool, post_tool, and post_agent hook events |
| mcp__* PreToolUse guards | MCP tool names are namespaced differently in Vibe (connector_<name>_<tool>) and do not match the Claude Code mcp__ prefix matchers |
| PowerShell pre-tool guards | Vibe routes Windows shells through git_bash or powershell tools; the PowerShell guard pair is deferred until the mapping is verified on Windows |

## Argument substitution

`$ARGUMENTS` placeholders in command bodies are rewritten to "(the text typed after the skill name)" because Vibe passes the text typed after the skill name as part of the user turn.
