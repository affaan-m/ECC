# マーケティングキャンペーン

単にリリースするだけでなく、コンバージョンするローンチキャンペーンを計画・実行する。

## 有効化するタイミング

- プロダクトまたはフィーチャーローンチを計画する時
- 単一のプロダクトブリーフから完全なコンテンツスイートを構築する時
- コピーを書く前にポジショニングとキャンペーンアングルを定義する時
- 複数のコンテンツタイプをチャネル横断でオーケストレーションする時
- コンバージョン品質とブランド一貫性のためにコピーをレビューする時

## 絶対条件

1. コピーを書く前にポジショニングを定義する。すべてのコピーはアングルから流れる。
2. オーディエンスの言語や恐れを知っていると仮定する前にリサーチする。
3. 各成果物はキャンペーンアーク内で 1 つの明確な目的を果たす必要がある。
4. あらゆるフォーマット・チャネルにおいて、形容詞より具体性が勝る。
5. 同じボイスがすべてのチャネルとすべてのコンテンツに流れなければならない。
6. 品質ゲートを通過しないコピーはリリースしない。

## キャンペーンワークフロー

### フェーズ 1: リサーチ

`market-research` を使用して:
- ターゲットオーディエンスをプロファイリングする（ジョブズトゥビードン、恐れ、言語、彼らが使う代替手段）
- 3 社以上の直接または隣接する競合をマッピングする（ポジショニング、ギャップ、メッセージングの弱点）
- キャンペーンアングルが活用する 1〜3 のオーディエンスインサイトを特定する

成果物: 短いリサーチブリーフ（オーディエンスプロファイル + 競合サマリー + キーインサイト）。

### フェーズ 2: ポジショニング

以下を作成する:
- コア便益ステートメント（1 文、フィーチャーリストなし、専門用語なし）
- ポジショニング式: 「[製品] は [オーディエンス] が [メカニズム] によって [成果] を達成するのを助ける」
- キャンペーンアングル: キャンペーン全体が生きる特定の緊張感、インサイト、またはモーメント
- トーンプロファイル: 執筆前に確定する（永続的でセッション再利用可能なボイスキャプチャには `brand-voice` に委任する）

ポジショニングとアングルが承認されるまでコピーを書かない。

### フェーズ 3: コンテンツ制作

この順序で制作する — 各レイヤーが次を情報提供する:

1. **ランディングページコピー**（すべてのセクション: ヒーロー、問題、解決策、フィーチャー、仕組み、証拠、CTA）
2. **メールシーケンス**（各メールに 1 つの目的; アークに従う: 問題 → 教育 → 煽り → 解決策 → 証拠 → 緊急性 → 最終 CTA）
3. **ソーシャル投稿**（`content-engine` を通じてプラットフォームネイティブ; LinkedIn と X は異なるフォーマット、同じコピーをリサイズしたものではない）
4. **ショートフォーム動画スクリプト**（タイムスタンプブロック; 画面と耳のために書く、ページのためではない）
5. **広告コピーバリアント**（異なるアングルまたはオーディエンスセグメントをテストする 3〜4 バリアント）
6. **コンテンツカレンダー**（チャネル、タイプ、タイミング、依存関係を含む日別スケジュール）

### フェーズ 4: レビュー

すべての成果物をゲートする:
- すべてのヒーロー / アバブザフォールドコピーへの 5 秒テスト（対象者、提供価値、今行動する理由が明確か）
- CTA 監査（コンテンツ 1 本につき 1 つ、具体的で、獲得したもの — 押し付けではない）
- 全チャネルにわたるトーン一貫性チェック
- クレーム監査（すべてのクレームは具体的で裏付け可能）
- クロスチャネル一貫性（広告のクレームがランディングページと一致; メール本文が件名と一致）

## アウトプット契約

完全なキャンペーンが提供するもの:

1. **ポジショニングブリーフ** — アングル、コア便益ステートメント、トーンプロファイル
2. **ランディングページコピー** — ヒーロー、問題、解決策、フィーチャー、仕組み、証拠、CTA
3. **メールシーケンス** — 各メールの件名 + プレビュー + 本文 + CTA、日付と目的でラベル付け
4. **LinkedIn 投稿** — 異なるアングルを持つ 3 本以上のプラットフォームネイティブ投稿
5. **X 投稿** — 5 本以上のスタンドアロン投稿 + 1 スレッド
6. **ショートフォーム動画スクリプト** — ビジュアル方向メモ付きのタイムスタンプブロックスクリプト 2 本以上
7. **広告コピーバリアント** — バリアントごとの短いヘッドライン / 長いヘッドライン / 本文
8. **コンテンツカレンダー** — チャネル、コンテンツタイプ、タイミング、依存関係を含む日別スケジュール
9. **コピーレビューサマリー** — 公開前にフラグされた問題とオープンクエスチョン

## 品質ゲート

成果物を提供する前に:

- すべての成果物が同一の著者のように聞こえる
- 空虚な最上級表現や埋め草の形容詞が残っていない
- すべての CTA が具体的で獲得されたもの（「詳しく見る」「クリックしてください」は不可）
- プラットフォーム間でそのままのコピーが重複していない
- ヒーローコピーが 5 秒テストを通過する
- メールの件名がメール本文と一致する（釣り見出しなし）
- 広告のクレームがランディングページのクレームと正確に一致する
- そのカテゴリーの他の製品にそのまま使用できるコピーが残っていない

## 禁止事項

以下はすべて削除して書き直す:

- 「ゲームチェンジャー」「革命的」「ワールドクラス」「最先端」
- 「今日の競争が激しい環境において」
- 実際の締め切りに基づかない偽りの緊急性
- 具体性のない空虚な社会的証明（「何千人もの人が信頼しています」）
- 汎用的な CTA（「詳しく見る」「もっと知る」「こちらをクリック」）
- プラグインを抜いてそのまま競合のキャンペーンに使用できるコピー

## 関連スキル

- `brand-voice` — ソース由来のボイスキャプチャ（コンテンツ制作前に実行する）
- `content-engine` — プラットフォームネイティブのコンテンツ制作
- `crosspost` — マルチプラットフォーム配信
- `market-research` — オーディエンスと競合インテリジェンス
- `seo` — ランディングページコピーのオンページ最適化
