# 岗位打招呼话生成（指导版）

输入：**岗位描述文本** + **候选人简历路径**，产出：**3 个版本**（复杂/中度/简单）打招呼话。

本 skill 与 `job-greeting` 的唯一区别：**跳过岗位抓取步骤**，岗位信息由用户直接提供。其余（简历提取、匹配分析、3 版本生成、风格偏好记忆）完全一致。

## 工作流

### 步骤 1：解析输入

- 岗位描述：用户粘贴的文本，或指向一个文件路径
- 简历路径：支持 `.pdf`、`.md`、`.txt`
- 若岗位描述是 URL 而非文本，提示用户：可直接走 `job-greeting` 自动抓取；或请用户把岗位页面内容粘贴过来

### 步骤 2：提取岗位要点

从岗位描述中提取：

- 岗位名称
- 任职要求（硬性条件）
- 加分项（优先条件）
- 对接人姓名（如有）
- 行业/公司背景

### 步骤 3：提取简历文本

```bash
python3 <skill_dir>/scripts/extract_resume.py <简历路径>
```

### 步骤 4：匹配分析

构建「岗位要求 vs 简历优势」对照表，找出 4-6 条强匹配点；标记明显短板用于提醒。

### 步骤 5：生成 3 个版本打招呼话

**先查风格偏好**：
- 已有偏好 → 以该版本为主输出，附另外两版供备选
- 无偏好 → 输出完整 3 版（复杂 ~200 字 / 中度 ~150 字 / 简单 ~100 字），让用户挑选

产出后分别标注【复杂版】【中度版】【简单版】，单独提醒明显短板；首次询问偏好并记忆。

## 风格偏好记忆

- 用户选定版本偏好保存到 Claude 记忆（feedback 类型），key 如 `job-greeting-style`
- 之后按偏好为主输出，**不再每次询问**；仅当用户明确说"调整风格/换个版本"时重新挑选并更新

## 生成规范速查

1. 称呼岗位对接人（未知用"老师/您好"）
2. `{称呼}您好，看到您在招{岗位名}岗位。`
3. 正文突出：项目经验 / 开发能力 / 大模型与核心技术栈，每条呼应岗位要求
4. 去AI化：无编号、无排比、口语自然
5. 一段连续文本，无换行无多余空格
6. 长度：复杂 ~200 / 中度 ~150 / 简单 ~100 字
7. 结尾：`简历已附上，期待与您进一步沟通，谢谢！` 或 `~`
8. 只写真实经历，短板另行提醒
