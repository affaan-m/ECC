## Evidence and gates

The pinned source provides four audited pre/post-tool projections plus lifecycle and Hookify runtimes. Synthetic fixtures test parsing and subprocess behavior; they do not prove host event delivery, PowerShell coverage, agent restrictions, authenticated integrations or OS parity. Native evidence must identify SHA, CLI version, OS, installation mode, case ID, redacted payload and result.

P00 remains partial until the Windows discovery, deny, post-tool and checkpoint/resume cases run. P01 owns contract and gate budgets; P02–P11 implement/review the recorded destinations; P12 owns M1 native certification; P13 adds plugin certification; P14 owns M2 release checks. No implementation or certification is inferred from an entry point count.

Use the machine-readable [inventory](../manifests/copilot-capabilities.json) for individual rows. Baseline execution results and environment evidence belong in a separate run record; regeneration never fabricates test results.
