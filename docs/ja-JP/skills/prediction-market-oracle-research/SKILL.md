# 予測市場オラクルリサーチ

予測市場をデータソース、予測入力、オラクル的シグナル、または意思決定インテリジェンスレイヤーとして活用する場面でこのスキルを使用する。

## ガードレール

- 市場価格を客観的な事実として扱わない。
- 投資アドバイスや取引推奨は提供しない。
- 取引所の仕組み、流動性、インセンティブ、解決ルールを、暗示されたシグナルから切り離して評価する。
- 市場操作、流動性の薄さ、古くなった市場、曖昧な結果については明示的に指摘する。
- オンチェーンまたは実行連動型システムの場合は、書き込み権限を付与する前に `llm-trading-agent-security` を実行する。

## リサーチワークフロー

1. シグナルが情報提供を目的とする意思決定を定義する。
2. 関連する市場、イベント、タグ、取引所を特定する。
3. タイムスタンプとソースリンクを付けて市場が示す確率を記録する。
4. シグナルの品質を評価する:
   - 流動性
   - スプレッド
   - 市場の設立年月
   - トレーダーやインセンティブの集中度（判明している場合）
   - 解決権限
   - 地域制限またはアカウント制限
5. 非市場ソース（財務書類、ニュース、世論調査、リサーチ、顧客データ、社内 KPI など）と比較する。
6. 該当する意思決定に対してシグナルが使用可能か、弱いか、不適切かを判断して推奨事項を述べる。

## 統合パターン

- リサーチアシスタント: 人間のアナリスト向けにソース根拠のあるコンテキストを提供する。
- ダッシュボードシグナル: 内部指標と並べて市場が示す確率を表示する。
- エージェントメモリ入力: 後から参照できるタイムスタンプ付きシグナルとして保存する。
- アラート入力: 確率、スプレッド、流動性が閾値を超えた際に通知する。
- シナリオプランニング: 取引を自動化せずに複数のイベント結果を比較する。

## 出力仕様

以下の順で出力する:

1. 意思決定コンテキスト
2. 市場ソース
3. シグナル品質
4. 比較ソース
5. 統合に関する推奨事項
6. 注意事項

末尾に必ず以下を付記する:

```text
Prediction-market signals are informational inputs, not investment advice.
```
