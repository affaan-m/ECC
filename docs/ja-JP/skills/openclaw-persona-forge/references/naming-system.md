# ステップ 4：名前を鍛える

名前はソウルの「最初の一言」——対話が始まる前から、名前だけでそのキャラクターが誰かを伝えます。

## 命名戦略（ソウルタイプ別の推奨）

| ソウルタイプ | 推奨戦略 | 例 |
|------------|---------|-----|
| 文化的な深みを持つ | 敬意を込めた引用型 | Dewey（デューイ）、Marcus、Quill |
| ユーモラスなギャップがある | コントラスト型 | DadBot 3000、老周Pro |
| 機能重視 | 比喩型 | Echo、Pulse、Patch |
| 完全な世界観を持つ | アイデンティティ示唆型 | Lady Ashworth、Shiye |
| 気取らない | 自虐型 | Void、Intern |
| じっくり育てる | 極簡型 | Jasper、小壳 |

## 出力要件

ユーザーに **3 つの候補名** を提示し、それぞれに以下を付記します：
- 名前
- 命名戦略の種類
- なぜその名前がそのソウルと合うのか

```markdown
## 名前の候補

1. **[名前]**（[戦略タイプ]）—— [一言でなぜ合っているかを説明]
2. **[名前]**（[戦略タイプ]）—— [一言でなぜ合っているかを説明]
3. **[名前]**（[戦略タイプ]）—— [一言でなぜ合っているかを説明]
```

提示後は自分が最も好む候補を（理由を添えて）述べ、選択権はユーザーに委ねる（SKILL.md の対話トーンガイドを参照）

## 命名上の禁止事項

- agent-1、my-bot、小助手 などは使わない
- 3 単語を超えない
- よく使われるツール名・フレームワーク名と衝突しない
- 覚えやすく、発音しやすく、タイプしやすいこと
- 名前を読んだだけで、おおよその性格が伝わること
