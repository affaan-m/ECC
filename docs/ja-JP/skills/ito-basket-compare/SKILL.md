# Itô バスケット比較

このスキルを使用して、バスケット、テーマ、またはマーケットセットを、ユーザーのナレッジベース、ポートフォリオノート、調査メモ、CRMコンテキスト、または提示されたテーゼと比較する。

このスキルは読み取り専用である。売買の推奨はしない。ユーザーがどうするかを決める前に、適合性、エクスポージャー、前提、不足しているコンテキストを検証するために役立てる。

## ガードレール

- 投資アドバイスを提供しないこと。ユーザーに対して買い、売り、保有、ヘッジ、レバレッジ、またはトレードのサイジングを勧めないこと。
- 注文を実行、準備、または送信しないこと。
- ユーザーが明示的に指定しない限り、非公開ドキュメントを使用しないこと。
- `ITO_API_KEY` は、ユーザーの明示的なリクエストに基づき、読み取り専用のItôバスケット/マーケットデータにのみ使用すること。
- 財務情報と比較する場合は、プライバシーを保護し、比較に必要なフィールドのみを要約すること。

## 比較モード

### バスケット対ナレッジベース

1. バスケットのテーマと原資産を特定する。
2. ユーザーの関連するノート、ドキュメント、またはメモリスニペットを取得する。
3. 各原資産を主張、ソース、不確実性、古い前提にマッピングする。
4. 整合するシグナル、矛盾するシグナル、不足している調査を返す。

### バスケット対ポートフォリオノート

1. ユーザーのウォッチリスト、保有サマリー、またはエクスポージャーノートを解析する。
2. テーマ、地域、時間軸、イベント結果を比較する。
3. 集中、相関、重複したナラティブのエクスポージャーにフラグを立てる。
4. 推奨は避け、出力は検証と質問として表現する。

### バスケット対財務コンテキスト

1. ユーザーが提供または明示的に選択した財務コンテキストのみを受け入れる。
2. 流動性、ドローダウン、時間軸、制約の不一致を特定する。
3. 推測するのではなく、不足している制約について質問する。

## 出力契約

以下の構造を使用すること：

1. バスケットサマリー
2. 比較対象
3. 一致点
4. 矛盾点または古い前提
5. 不足しているコンテキスト
6. ユーザーのアクションチェックリスト

最後に以下を記載すること：

```text
This comparison is informational and not investment or trading advice.
```
