# 简历定制（resume-tune）

输入：**完整版简历** + **目标岗位 JD**，产出：**定制简历 Markdown**。

## 三种模式

| 模式 | 输入 | 产出 |
|---|---|---|
| **单岗位模式** | 1 个岗位 JD（某公司） | 针对该 JD 精确匹配的深度定制简历 + 定制说明 |
| **普遍模式** | 5-10 个相似岗位 JD | 覆盖共性要求、可投递多个相似岗位的通用定制简历 |
| **关键字检索模式** | 岗位关键词（如"FDE 大模型"）+ 可选城市/薪资 | 自动搜索岗位并提炼共性要求 → 按共性定制简历 |

## 工作流

### 步骤 1：解析输入

- 完整版简历路径（推荐 `master-resume.md` 或 PDF，PDF 用 `../job-greeting/scripts/extract_resume.py` 提取）
- 目标 JD：
  - 单岗位模式：1 个 JD（文本或链接）
  - 普遍模式：多个 JD（文本列表 / 多个链接 / 混合）
  - 关键字检索模式：岗位关键词（如 FDE、AI 产品经理）+ 可选城市/薪资范围

### 步骤 2：获取 JD 内容

- **文本**：直接使用
- **链接**：复用 `job-greeting` 的浏览器抓取经验——
  - browser-mcp（graph-memory）优先，`browser_open` + `browser_snapshot`（显式传 `tab_id`）
  - 快照必须包含"职位描述/任职要求/岗位职责"，未确认前不要继续（判定标准与 `job-greeting` 相同）
  - 遇登录墙/验证码：可见模式扫码登录，或让用户粘贴 JD 文字
- **关键字检索模式**：调用 `job-search` skill——
  - 用浏览器搜索关键词岗位，获取 5-10 个岗位列表 + 通用岗位要求总结
  - 严格遵循 `job-search` 的反爬注意事项（headful + 已登录 profile、**低频操作**、模拟人类节奏）

### 步骤 3：分析 JD（定制依据）

**单岗位模式**：从 JD 提取——
- 岗位职责关键词（做什么）
- 任职要求（硬性：年限、语言、框架、领域）
- 加分项（优先：工具、平台、经验）
- 公司/行业背景

**普遍模式**：对多个 JD 做**关键词频次统计**，提炼高频共性要求——
- 高频技能词：如 Python、大模型、Agent、RAG、K8s、Hadoop
- 高频领域词：如舆情、金融、SaaS
- 共性的年限/学历要求
- 输出一张"共性要求表"，作为定制依据

**关键字检索模式**：直接使用 `job-search` 输出的"通用岗位要求总结"作为定制依据（岗位本质、共性硬性要求、共性能力要求、加分项）

### 步骤 4：匹配与定制

从完整版简历中按相关度筛选与定制：

1. **个人总结**：按岗位重写，融入 JD 高频关键词（如"熟悉大模型微调与 RAG/Agent 落地""具备大规模集群性能调优经验"），突出岗位最看重的 1-2 点
2. **核心技能**：按 JD 要求重新排序——JD 明确要求的技术排在前面；弱相关或未要求的技能压缩或删减
3. **工作经历**：保留与岗位相关的职责描述，弱相关段压缩为 1-2 行
4. **项目经验**：精选与岗位最相关的 3-5 个项目，**保留并强化**量化成果与关键责任；弱相关项目压缩或省略
5. **教育/荣誉**：保留，可不调整

**诚实原则（强制）**：
- 只做**重排、聚焦、删减、措辞优化**，**不虚构**经历、技能、数据
- 若 JD 要求存在明显短板（如某语言、某行业经验），在"定制说明"中如实标注，不硬写进简历

### 步骤 5：输出定制简历

标准结构：

```
# 姓名 · {目标岗位方向} 简历
## 基本信息        （姓名/学历/年限/联系方式）
## 个人总结        （按岗位定制）
## 核心技能        （按 JD 排序，6-10 项）
## 工作经历        （相关职责保留）
## 项目经验        （精选相关项目，量化成果加粗）
## 教育背景
```

- 输出为 Markdown 文件（写入用户指定路径或当前目录 `resume-{岗位方向}.md`）
- 附**定制说明**：
  - 单岗位模式：针对该 JD 强化了哪些点、覆盖了哪些任职要求、存在哪些短板
  - 普遍模式：覆盖了哪些共性要求、该简历适用于哪些方向的岗位
  - 关键字检索模式：基于哪些搜索岗位提炼的共性要求、该简历适用于哪些方向的岗位
- 提醒用户核对联系方式与定制后的内容

### 步骤 6（可选）：生成美观 HTML 打印版

- 生成定制简历后，**询问用户**是否需要 HTML 打印版（或按用户习惯默认生成）：
  - 需要 → 调用 **`html-print-optimizer`** skill，输入为步骤 5 输出的定制简历 Markdown + 目标岗位方向
  - 产出：A4 打印版 HTML 简历（蓝色主题、模块不跨页、浏览器直接打印 PDF）
- 若用户只想要 Markdown，跳过此步骤
- 参考 `../html-print-optimizer/SKILL.md` 的排版与分页规范
