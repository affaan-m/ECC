# Itô トレードプランナー

ユーザーが予測市場のアイデア、バスケット調整、会場比較、または手動実行計画のための構造化されたワークシートを必要とする場合に、このスキルを使用する。

このスキルは意図的に非実行型である。ユーザーが手動でレビューできるチェックリストとパラメータ表を作成する。

## ガードレール

- トレードが良い、悪い、最適、または推奨であると述べないこと。
- 投資アドバイスやポジションサイジングのアドバイスを提供しないこと。
- 注文を発注、キャンセル、ルーティング、または署名しないこと。
- 秘密鍵、シードフレーズ、取引所パスワード、またはウォレットの認証情報を要求しないこと。
- ワークフローが調査から実行可能なツールに移行する前に、明示的なユーザー承認を必要とすること。

## 計画ワークフロー

1. ユーザーのアイデアを中立的な仮説として言い換える。
2. マーケット、会場、原資産、解決ルール、手数料、データ鮮度の制約を特定する。
3. `ITO_API_KEY` が設定されており要求された場合、Itôバスケットのメタデータを読み取る。
4. 手動ワークシートを作成する：
   - マーケット/原資産
   - 会場
   - データソース
   - 現在観測可能な価格またはステータス
   - 解決ルール
   - 流動性に関する注意事項
   - オープンクエスチョン
   - 手動アクションリンクまたは次のレビューステップ
5. 自動化、鍵、会場認証、または資本制約について議論する前に `prediction-market-risk-review` を実行する。

## 使用可能な表現

使用する表現：

- "manual planning worksheet"
- "questions to answer before acting"
- "observable venue data"
- "risk and constraint review"

避ける表現：

- "you should buy/sell"
- "best trade"
- "guaranteed"
- "risk-free"
- "optimal size"

## 出力契約

すべての計画の末尾に以下を記載すること：

```text
This is a planning worksheet, not investment or trading advice. Review venue
rules and make any trading decisions yourself.
```
