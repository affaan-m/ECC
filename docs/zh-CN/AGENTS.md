# Everything Claude Code (ECC) - 智能体指令

这是一个**生产就绪的 AI 编码插件**，提供 64 个专业代理、261 项技能、91 条命令以及自动化钩子工作流，用于软件开发。

**版本:** 2.0.0-rc.1

## 核心原则

1. **代理优先** - 将领域任务委托给专门代理。
2. **测试驱动** - 先写测试，再实现代码。
3. **安全优先** - 永远不要牺牲安全性。
4. **性能优先** - 优先并行化和可重复的工作流。
5. **先计划，再执行** - 复杂任务先梳理，再动手。

## 可用代理

| 代理 | 作用 | 适用场景 |
|------|------|----------|
| planner | 生成实现蓝图与步骤 | 新功能、复杂重构 |
| code-reviewer | 审查变更 | 提交前质量检查 |
| security-reviewer | 安全审计 | 认证、授权、敏感数据 |
| build-error-resolver | 修复构建问题 | 构建失败、依赖问题 |
| e2e-runner | 验证端到端流程 | 流程回归、关键路径 |

## 代理编排

主动使用代理，无需等待用户逐个提示：
- 复杂功能请求 -> **planner**
- 刚修改过的代码 -> **code-reviewer**
- 认证与授权变更 -> **security-reviewer**
- 构建失败 -> **build-error-resolver**

独立操作可以并行执行，减少等待时间。

## 工作流表面策略

- `skills/` 是规范的工作流表面。
- 新的工作流贡献应优先进入 `skills/`。
- `commands/` 只保留兼容性的斜杠入口，主要用于迁移或跨平台一致性。

## 项目结构

```
agents/          - 64 个专业子代理
skills/          - 261 个工作流技能和领域知识
commands/        - 91 个斜杠命令
hooks/           - 基于触发的自动化
rules/           - 始终遵循的指南（通用 + 每种语言）
scripts/         - 跨平台 Node.js 实用工具
mcp-configs/     - 14 个 MCP 服务器配置
tests/           - 测试套件
```

## 迁移说明

- `commands/` 仍保留在仓库中用于兼容，但长期方向是以 `skills/` 为主。
- 新工作流应优先实现为技能，再在需要时增加命令包装层。

## 成功指标

- 新功能能通过专门代理进入正确的工作流。
- 命令只作为兼容入口，不成为唯一实现路径。
- 钩子、技能和规则在不同平台上保持一致。
