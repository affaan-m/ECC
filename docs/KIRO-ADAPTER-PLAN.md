# Kiro First-Class Adapter — Implementation Plan

Goal: promote Kiro from a hand-maintained `.kiro/` snapshot to a first-class
ECC install target (parity with `codex` / `gemini` / `zed`), with a generator
that regenerates the committed `.kiro/` tree from canonical ECC sources so it
never drifts.

## Architecture

```
canonical sources                      generator                committed adapter        install adapter
  agents/        ──┐                                                .kiro/agents/
  skills/        ──┤   scripts/generate-kiro-adapter.js  ───────►   .kiro/skills/    ──►  kiro-project.js
  rules/         ──┤   (maintainer build step)                      .kiro/steering/       (./install.sh
  hooks/         ──┤                                                .kiro/hooks/           --target kiro)
  mcp-configs/   ──┘                                                .kiro/settings/
```

- `.kiro/` is a committed platform dir (like `.gemini/`), regenerated by the
  generator. The install target copies it into a user's project `.kiro/`.
