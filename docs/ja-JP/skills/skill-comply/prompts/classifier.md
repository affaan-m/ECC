コーディングエージェントのセッションから得られたツール呼び出しを、期待される動作ステップと照合して分類します。

各ツール呼び出しについて、それがどのステップに該当するか（該当する場合）を判定してください。1件のツール呼び出しは最大1つのステップにのみマッチします。

ステップ:
{steps_description}

ツール呼び出し（番号付き）:
{tool_calls}

ステップIDをキー、マッチしたツール呼び出し番号のリストを値とするJSONオブジェクトのみを返してください。
少なくとも1件のマッチがあるステップのみを含めてください。ツール呼び出しがどのステップにもマッチしない場合は省略します。

レスポンス例:
{"write_test": [0, 1], "run_test_red": [2], "write_impl": [3, 4]}

ルール:
- マッチはキーワードではなく、ツール呼び出しの「意味」に基づいて判定すること
- `test_calculator.py` への Write はテストファイルの書き込みとみなす（内容が実装に近くても同様）
- `calculator.py` への Write は実装の書き込みとみなす（テストヘルパーが含まれていても同様）
- `pytest` を実行して "FAILED" が出力された Bash は RED フェーズのテスト実行
- `pytest` を実行して "passed" が出力された Bash は GREEN フェーズのテスト実行
- 各ツール呼び出しは最大1つのステップにのみマッチさせること（最も適切なものを選ぶ）
- どのステップにもマッチしないツール呼び出しは含めないこと
