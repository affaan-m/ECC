# 岗位关键词搜索（job-search）

输入：**关键词**（+ 可选：城市 / 薪资范围 / 抽取数量），产出：**岗位样本列表 + 通用岗位要求总结**。

## 工作流

### 步骤 1：解析输入

- 关键词（必填）：如 FDE、AI 产品经理
- 城市（可选）：默认北京（`city=101010100`）或不限
- 薪资范围（可选）
- 抽取数量（可选，默认 5-10 个）

### 步骤 2：浏览器搜索

- 使用已配置的浏览器，**优先可见模式（headful）+ 已登录 profile 复用登录态**
- 打开搜索页：`https://www.zhipin.com/web/geek/jobs?query={关键词}&city={城市码}`
- 等待 SPA 加载完成（5-10 秒，轮询直到页面含岗位列表）
- 提取搜索结果：岗位名、公司、薪资、经验、学历、城市、岗位 URL

**反爬注意事项（BOSS 直聘实测，务必遵守）**：

- **headless 极易触发"安全验证"**，优先用可见模式（headful）并复用已登录 profile
- 风控是 **IP 级别**：**低频操作**，每次请求间隔 3-5 秒，尽量在**一次会话**内完成
- 不要高频刷新、反复点击、并发请求——会加剧风控
- 若遇到验证码页（"安全验证"），**立即停止自动操作**，让用户手动完成验证后继续
- 直接访问 `job_detail/{id}.html` 常被重定向（需 securityId），优先从搜索列表页提取数据或点击进入
- 薪资可能以图标字体显示（内联文本乱码），根据字符/数字推断区间
- **持续无法获取时**（多次验证/空白/重定向）：停止抓取，改用**截图 + 文字识别（OCR）**——让用户在自己已登录的浏览器打开岗位页/搜索页截图，OCR 抽取岗位文字后再分析

### 步骤 3：薪资筛选（可选）

- 如需按薪资筛选：模拟人类点击"薪资待遇"选择区间（间隔等待），或基于已提取列表按薪资区间归类
- 控制操作次数，一次会话内完成

### 步骤 4：抽取岗位

- 选取 5-10 个**代表性**岗位（覆盖不同公司、薪资区间、经验要求）
- 可选：低频访问少数岗位详情页获取完整 JD（每次间隔 3-5 秒，控制总量，避免频繁）

### 步骤 5：总结通用岗位要求

从岗位列表 + 已获取的 JD 提炼，输出结构化总结：

1. **岗位本质**：该岗位做什么、在组织中的定位
2. **共性硬性要求**：学历、经验年限、薪资区间（主流区间）
3. **共性能力要求**：技能维度表（如 AI 快速原型 / 大模型技术 / 开发能力 / 客户交付 / 部署运维）
4. **共性加分项**：行业经验、平台、工具

## 输出

- **岗位样本列表**（表格：岗位名 / 公司 / 薪资 / 经验 / 学历）
- **通用岗位要求总结**（上述结构）
- **可信度说明**：哪些来自完整 JD、哪些来自列表信息推断，避免误导

## 与 resume-tune 配合

- 输出可作为 `resume-tune` **关键字检索模式**的输入：自动获取的岗位通用要求 → 作为简历定制依据
- 调用方式：`用 job-search 搜索 {关键词}，然后用 resume-tune 按结果定制简历`
