# Support

Pick the shortest route for what you need. Every route below is public except
the security one.

## I hit a problem installing or running ECC

Open the [install or runtime problem form](https://github.com/affaan-m/ECC/issues/new?template=install-problem.yml).

Before you do, run the two commands that answer most reports:

```bash
npx ecc-universal doctor
ecc feedback
```

`doctor` prints the harness, Node version, install scope, and hook profile.
`feedback` prints the routes on this page. Neither uploads anything.

## I have a question about how to use ECC

Ask in [Q&A discussions](https://github.com/affaan-m/ECC/discussions/categories/q-a)
or in [Discord](https://discord.gg/36yGMHGFbR). Q&A is searchable and helps the
next person, so prefer it for anything that is not a live back-and-forth.

## I want to suggest something

- Small idea or reaction: [quick feedback form](https://github.com/affaan-m/ECC/issues/new?template=quick-feedback.yml) (about 20 seconds).
- Full proposal: [feature request form](https://github.com/affaan-m/ECC/issues/new?template=feature-request.yml).
- Open-ended thinking: [Ideas discussions](https://github.com/affaan-m/ECC/discussions/categories/ideas).

## I found a security problem

Do not open a public issue. Use the
[private advisory form](https://github.com/affaan-m/ECC/security/advisories/new)
and read [SECURITY.md](SECURITY.md) first.

## I want to contribute

[CONTRIBUTING.md](CONTRIBUTING.md) has the file formats, the test command, and
the review turnaround you can expect. Issues labelled
[good first issue](https://github.com/affaan-m/ECC/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
are scoped so that a first pull request does not need repo-wide context.

## Response expectations

ECC is maintained by a small team with sponsor and Pro funding. Triage aims for
one business week on issues and pull requests. Security reports are handled
first. If something has gone quiet past that window, a comment on the thread is
welcome and is not considered noise.
