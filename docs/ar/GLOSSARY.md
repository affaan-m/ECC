# مسرد المصطلحات / Glossary

مسرد المصطلحات الموحد للترجمة العربية لمشروع ECC.

المبدأ التوجيهي: تظل أسماء واجهات ECC الأساسية والمصطلحات التقنية المعتمدة باللغة الإنجليزية كما هي (`agents/`، `skills/`، `hooks/`، `rules/`، `commands/`) عندما يكون تعريبها سبباً في صعوبة ربط النص باسم المجلد أو الأمر البرمجي أو واجهة الاستخدام في بيئة العمل. في السياق الوصفي العام، يمكن استخدام المقابل العربي الموضح أدناه.

| المصطلح بالإنجليزية (English) | المقابل بالعربية (Arabic) | ملاحظات وسياق الاستخدام |
|---|---|---|
| Agent | Agent / وكيل | اسم واجهة `agents/` البرمجية؛ الجمع: وكلاء |
| Skill | Skill / مهارة | اسم واجهة `skills/`؛ الجمع: مهارات |
| Hook | Hook / خُطاف أو معالج أحداث | اسم واجهة `hooks/`؛ معالجات أحداث بيئة العمل |
| Command | Command / أمر | اسم واجهة `commands/`؛ عامةً: "أمر برمجيات" |
| Rule | Rule / قاعدة | اسم واجهة `rules/`؛ عامةً: "قاعدة توجيهية" |
| Harness | بيئة تشغيل الوكيل (Harness) | يُبقى على Harness كمصطلح تقني أصيل لنظام التشغيل |
| Instinct | Instinct / غريزة برمجية | مصطلح مستخدم في ميزة Continuous Learning |
| Plugin | إضافة (Plugin) | حزمة برمجية متكاملة لبيئة العمل |
| Marketplace | سوق الإضافات (Marketplace) | مستودع الإضافات المعتمد |
| Worktree | شجرة عمل (Worktree) | مصطلح Git لبيئات العمل المتوازية |
| Subagent | وكيل فرعي (Subagent) | وكيل منبثق لمهمة محددة |
| Frontmatter | الترويسة التعريفية (Frontmatter) | بيانات YAML الوصفية أعلى الملفات |
| Continuous Learning | التعلّم المستمر | ميزة استخلاص التجارب وتطوير الأنماط |
| Memory | الذاكرة / نظام الذاكرة | كمفهوم بنيوي في ECC: مستودع الذاكرة |
| Context window | نافذة السياق | سعة الرموز المتاحة للنموذج في الجلسة |
| Token | رمز / وحدة معالجة (Token) | أصغر وحدة نصية يفهمها النموذج |
| Coverage | نسبة التغطية (Test Coverage) | تغطية الاختبارات البرمجية للكود |
| Test-Driven Development | التطوير الموجه باختبارات | يُحافظ على الاختصار TDD |
| Code review | مراجعة الكود البرمجي | فحص جودة وشروط الكود |
| Refactoring | إعادة هيكلة الكود (Refactoring) | تحسين بنية الكود دون تغيير سلوكه |
| Pull request | طلب السحب (PR) | طلب دمج التعديلات في المستودع |
| Commit | إيداع / تثبيت (Commit) | تسجيل التغييرات في سجل Git |
| Branch | فرع (Branch) | مسار تطوير مستقل |
| Merge | دمج (Merge) | دمج فرع في آخر |
| Build | بناء (Build) | إنتاج الحزمة البرمجية النهائية |
| Deploy | نشر (Deploy) | إطلاق البرمجية في بيئة التشغيل |
| Pipeline | خط أنابيب المعالجة (Pipeline) | مسار أتمتة العمليات البرمجية |
| Orchestration | التنسيق التلقائي (Orchestration) | إدارة تفاعل الوكلاء والمهام |
| Repository | مستودع (Repository) | اختصاراً: مستودع (Repo) |
| Dependency | تبعية برمجية (Dependency) | الجمع: تبعيات |
| Edge case | حالة طرفية / حدّية | سيناريو غير تقليدي في عمل البرنامج |
| Best practice | أفضل الممارسات | المعايير الهندسية الفضلى الموصى بها |
| Anti-pattern | نمط مضاد (Anti-pattern) | ممارسة برمجية تبدو حلاً ولكنها تخلق مشاكل |
| Middleware | برمجية وسيطة (Middleware) | طبقة اعتراض ومعالجة الطلبات |
| Endpoint | نقطة نهاية (Endpoint) | رابط واجهة برمجة التطبيقات (API) |
| Schema | مخطط هيكلي (Schema) | توصيف بنية البيانات وقواعدها |
| Payload | حمولة البيانات (Payload) | البيانات المرسلة في الطلب البرمجي |
| Callback | رد نداء (Callback) | دالة تُنفذ كرد على حدث معين |
| Checkpoint | نقطة فحص / استعادة | نقطة حفظ مرحلية لحالة العمل |
| Linter | أداة فحص الكود (Linter) | مدقق المعايير الصياغية للكود |
| Formatter | أداة تنسيق الكود (Formatter) | منظم شكل وترتيب الكود البرمجي |
| Staging | بيئة الاختبار والتجهيز (Staging) | بيئة تحاكي بيئة الإنتاج قبل الإطلاق |
| Production | بيئة الإنتاج (Production) | البيئة الحية المستخدمة فعلياً |
| Debugging | تنقيح الأخطاء (Debugging) | تشخيص وإصلاح العلل البرمجية |
| Logging | تسجيل السجلات (Logging) | تدوين أحداث وسجلات النظام |
| Monitoring | المراقبة والمتابعة (Monitoring) | رصد أداء واستقرار الخدمات البرمجية |
| Rate limit | حد معدل الطلبات (Rate Limit) | السقف الزمني المسموح به للطلبات |
| Retry | إعادة المحاولة (Retry) | تكرار تنفيذ عملية فشلت مؤقتاً |
| Fallback | خيار بديل / مسار تراجعي | آلية عمل بديلة عند تعذر المسار الأساسي |
| Sandboxing | العزل في بيئة آمنة (Sandboxing) | تشغيل الكود في بيئة محكمة معزولة |
| Sanitization | تنقية وتطهير البيانات | تنظيف المدخلات من الشوائب والرموز غير الآمنة |
| Selective install | التثبيت الانتقائي | تثبيت مكونات محددة وفق الاحتياج |
| Profile | ملف تعريف التثبيت (Profile) | إعداد مسبق لحزمة التثبيت |
| Component | مكوّن (Component) | عنصر معرف ضمن كتالوج المثبت |
| Module | وحدة نمطية (Module) | وحدة ملفات قابلة للتثبيت والنقل |
