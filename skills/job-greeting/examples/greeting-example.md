# 打招呼话示例（格式示例）

> ⚠️ 以下为**格式示例**：展示打招呼话的结构与风格。姓名、项目、公司均为占位符，
> 请替换为候选人的真实信息后再使用。均符合：去AI化、一段连续文本、无换行无空格、
> 突出项目经验/开发能力/大模型技术。

## 示例一：Forward Deployed Engineer (FDE) 类岗位

> 古老师您好，我是张三，8年大数据和AI全栈经验。近期落地过XX智能数据助手、XX智能运维等生产级AI项目，涉及大模型微调（QLoRA/GRPO）、RAG、Agent、MCP、LangGraph等技术，开发主要用Python和Java，平时也用Claude Code等AI编程工具快速做Demo，有多年客户现场交付经验。简历已附，期待沟通，谢谢！

**岗位关键要求**：5年+企业级技术交付、熟练使用 Cursor/Claude Code/Codex、AI 应用落地（Agent/RAG/MCP）、客户现场沟通。

## 示例二：AI 解决方案工程师类岗位

> 你好，看到您在招XX解决方案工程师岗位。我有8年大数据和AI落地经验，做过XX智能数据助手、XX智能运维等生产级AI项目，涉及大模型微调、RAG、Agent、MCP、LangGraph等技术，日常用Python做LLM API集成和数据处理，有多年客户现场交付和方案宣讲经验，也做过XX、XX等多行业数据分析，希望能跟您进一步沟通~

**岗位关键要求**：精通 Python、大模型应用落地、LangGraph/Agent/RAG、客户访谈与方案设计、行业数据分析。

## 结构拆解

| 部分 | 说明 |
|---|---|
| 称呼 | 用岗位页对接人姓名（如"古老师"）或省略用"你好" |
| 开门见山 | "看到您在招{岗位名}岗位" |
| 项目经验 | 1-2 个最有代表性的生产级项目 |
| 开发能力 | Python + Java、Claude Code 等工具 |
| 大模型技术 | 微调、RAG、Agent、MCP、LangGraph |
| 结尾 | 简历已附 + 期待沟通 + 谢谢/~ |
