# Itô マーケットインテリジェンス

ユーザーが予測市場のコンテキスト、イベントディスカバリー、会場比較、バスケットテーマの探索、またはItô APIによるマーケットブリーフを必要とする場合に、このスキルを使用する。

これは公開テザースキルである。デフォルトでは公開ソースと連携できる。Itôベースのデータ呼び出しには、`ITO_API_KEY` を通じた明示的なAPIアクセスが必要である。

## ガードレール

- 投資、法律、税務、または取引アドバイスを提供しないこと。
- 実際の注文を発注、キャンセル、ルーティング、またはシミュレートしないこと。
- ユーザーが提供しない限り、ユーザーの財務状況を推測しないこと。
- Polymarket、Kalshi、Itô、X、Exa、GitHub、およびウェブデータをそれ自体では真実ではなくソース入力として扱うこと。
- 事実、市場が示唆するシグナル、および自身の解釈を分けて記載すること。

## ワークフロー

1. マーケットテーマ、会場、地域、時間軸を明確にする。
2. 会場のドキュメント/APIまたはソースに基づいた調査から公開市場データを収集する。
3. `ITO_API_KEY` が存在し、ユーザーがItôデータを明示的に要求した場合は、読み取りエンドポイントのみを呼び出し、アクセスがゲートされていることを明記する。
4. 会場間のイベント、原資産、流動性、手数料、解決方法、データレイテンシの違いを正規化する。
5. 意思決定ブリーフを作成する：
   - マーケット/イベントサマリー
   - 利用可能な会場と原資産
   - 流動性とデータ品質に関する注意事項
   - 関連するニュース/ソースのコンテキスト
   - ユーザーがアクションを取る前のオープンクエスチョン

## 有用なスキルチェーン

- `deep-research` または `exa-search`：ソースディスカバリーに使用する。
- `x-api`：Xアクセスが設定されている場合の公開ソーシャルシグナルディスカバリーに使用する。
- `market-research`：市場規模、競合、またはビジネスユースケースに使用する。
- `prediction-market-risk-review`：ワークフローがユーザーの資本、ポートフォリオデータ、または実行可能な認証情報に触れる前に使用する。

## 出力契約

ソースリンクと明確な注意書きを含むコンパクトなブリーフをデフォルトとする：

```text
This is market intelligence, not investment or trading advice.
```

アクセスが不足している場合は以下を記載する：

```text
Itô live basket/API data requires gated access. Request an ITO_API_KEY before
using Itô-backed reads.
```
