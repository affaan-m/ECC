# Rust 2024 compatibility

Rust 2024 became available in Rust 1.85. New projects can choose that edition while using a newer supported compiler. Existing projects retain their declared edition and MSRV unless migration is part of the task.

Review edition-sensitive changes rather than only changing `edition`:

- `extern` blocks require `unsafe extern`; verify foreign declarations manually.
- Unsafe operations inside an `unsafe fn` need explicit unsafe blocks to avoid the edition's default lint.
- Attributes including `no_mangle`, `export_name`, and `link_section` use unsafe-attribute syntax, with a rationale for their global/linker assumptions.
- `std::env::set_var` and `remove_var` are unsafe in Rust 2024; process-wide environment mutation needs a valid platform/threading argument. Pass environment values to child processes through their command configuration when that is the actual need.
- Match ergonomics, temporary drop scopes, return-position `impl Trait` captures, and the reserved `gen` keyword can affect existing code.

Use migration tooling only for an authorized migration and review its diff. `cargo fix --edition` helps apply compiler suggestions; it cannot prove FFI signatures, environment synchronization, or soundness.
