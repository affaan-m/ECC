# Source and adaptation

The active terminology-refinement workflow and compact glossary guidance are adapted from [Matt Pocock's domain-modeling skill](https://github.com/mattpocock/skills/tree/c55ee46073ed923f86ce59a5eb3b6d895095d1b7/skills/engineering/domain-modeling), pinned at `c55ee46073ed923f86ce59a5eb3b6d895095d1b7`, under the [MIT license](../LICENSE).

This is an in-place ECC adaptation, not another skill or an external runtime dependency. It preserves ECC's mapped glossary selection, evidence and authorization boundaries, and handoff to `architecture-decision-records`. It does not import a second ADR template, directory, numbering scheme, or lifecycle. The existing ECC context template is extended rather than replaced with a second glossary format.
