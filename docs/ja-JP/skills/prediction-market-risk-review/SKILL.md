# 予測市場リスクレビュー

ユーザーの金融コンテキスト、取引所認証、ポートフォリオデータ、自動化、または実行可能なツールに予測市場ワークフローが触れる前に、このスキルを使用する。

## レビューゲート

### アドバイス境界

- 出力が情報提供に限定されていることを確認する。
- 買い/売り/保有/ポジションサイズの推奨は除去する。
- ユーザーが手動で判断するステップを明示的に残す。

### 取引所・規制境界

- 取引所の利用規約、地域制限、アカウント制限、API ルールを特定する。
- 賭博、デリバティブ、有価証券、商品に関する曖昧性が存在する場合は、関連する法的レビューのためにフラグを立てる。
- 取引所の制限やレート制限を回避しない。

### データ品質

- 市場の流動性、スプレッド、解決ルール、古くなった価格、ソースのタイムスタンプを確認する。
- 公開取引所データと Itô ゲートデータを分けて扱う。
- ラベルなしで公開ソースとプライベートソースを混在させない。

### セキュリティ

- 秘密鍵、シードフレーズ、パスワードの要求や保存は行わない。
- `ITO_API_KEY` および取引所 API キーをログやドキュメントに残さない。
- デフォルトでは読み取り専用スコープを使用する。
- プライベート実装が実行機能を追加する前に、サーキットブレーカー、支出上限、ドライラン、人間による承認を必須とする。

### プライバシー

- ユーザーのポートフォリオ情報、金融情報、ナレッジベースデータを最小限に抑える。
- 公開成果物ではプライベートソースを編集・削除する。
- レビューに必要なフィールドのみを保持する。

## 出力仕様

以下の内容を返す:

1. レビュー対象のスコープ
2. 合格/警告/不合格の所見
3. ブロックされたアクション
4. 必要な軽減策
5. 安全な次のステップ

実行可能なステップが要求された場合は、別途実装計画とユーザーの明示的な承認を必須とする。
