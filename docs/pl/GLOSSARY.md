# Glosariusz / Glossary

Ujednolicona terminologia polskiego tłumaczenia ECC.

Nazwy powierzchni ECC oraz powszechne terminy techniczne pozostają po angielsku, gdy ich
spolszczenie utrudniałoby powiązanie tekstu z nazwą katalogu, poleceniem lub interfejsem.
W zwykłym opisie można użyć polskiego odpowiednika wskazanego poniżej.
