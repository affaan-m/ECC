# Intro to AI Engineering (Huyen Ch 1)

## Build vs Buy Framework
1. Is this application necessary? (business value)
2. Is AI needed? (rules/heuristics sufficient?)
3. Do I have to build it? (existing API?)

## FM Capabilities
| Good At | Not Yet Good At |
|---|---|
| Text gen, code, summarization | Factual consistency |
| Pattern matching unstructured | Complex multi-step reasoning |
| Creative writing | Long-context coherence |

## AI Stack Changes
- Model as a Service — few train, many consume
- Prompt engineering replaces feature engineering
- Context construction (RAG, agents) replaces data pipelines
- Evaluation becomes continuous

## AI Engineer vs ML Engineer
| ML Eng | AI Eng |
|---|---|
| Train from scratch | Build on FMs |
| Feature engineering | Prompt/context engineering |
| Model-centric | Product-centric |

## When to Use
- New AI project go/no-go
- Scoping AI requirements
